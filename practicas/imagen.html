Crea una imagen para tu proyecto

Crea una ilustración para una actividad cercana, cambia un detalle y revisa lo que comunica.

Volver al recorrido

¿La imagen muestra lo que tu proyecto puede ofrecer?

Crearás una ilustración conceptual para anunciar un taller ficticio de reparación textil. Puede servir como idea visual para un cartel. No es una fotografía del taller, de sus instalaciones ni de un producto real.

Tiempo orientativo: 25–40 minutos. Necesitas navegador, cuenta con acceso a generación de imágenes y un lugar donde guardar la imagen y tus prompts. Puedes hacer esta práctica sin haber completado la experiencia 01.

Herramienta y condiciones

Herramienta principal: Gemini, sección Imágenes. Permite crear una imagen a partir de texto y pedir ediciones concretas. La ayuda oficial explica generación, edición y descarga. Requiere iniciar sesión; la disponibilidad, la edición y los límites varían según edad, país y tipo de cuenta. No necesitas contratar un plan para seguir la guía: si la función no aparece, prepara el prompt y analiza una demostración docente.

Revisa composición, texto, defectos y si la escena puede inducir a error. Usa solo referencias propias o con permiso.

1. Define el uso y genera

  1. Decide dónde irá la imagen: cartel vertical, publicación cuadrada o cabecera horizontal. Deja espacio para el texto que añadirás después.
  2. Abre Gemini e inicia sesión. En la sección Imágenes, escribe el prompt; si la interfaz cambia, busca la opción equivalente de crear imágenes.
  3. Observa sujeto, entorno, composición y estilo antes de aceptar la primera versión.
Crea una ilustración conceptual cuadrada para anunciar un taller ficticio de reparación de ropa de una asociación local. En primer plano, manos adultas cosiendo un pequeño parche sobre una prenda sencilla; al fondo, una mesa compartida y materiales básicos. Composición clara con espacio libre arriba para añadir un título después. Estilo de ilustración cálida y sencilla, sin letras, logotipos, rostros reconocibles ni maquinaria. No muestres instalaciones concretas como si fueran reales.

Ejemplo de resultado esperado, ilustrativo: manos y tela reconocibles, una mesa compartida y zona libre para el título. El resultado real puede diferir.

2. Decide un cambio pequeño

Escoge un aspecto que dificulte el propósito: manos deformadas, poco espacio para el título o demasiados elementos. Pide solo ese cambio y compara las dos imágenes.

Mantén la escena y el estilo de ilustración. Cambia solo la composición: deja más espacio despejado en la parte superior para un título que añadiré después. Conserva las manos, el parche y la mesa. No añadas texto.

Si la herramienta no conserva bien la imagen, describe otra vez los elementos que deben permanecer.

3. Comprueba y conserva

  • ¿Se entiende la actividad y cabe el texto del cartel?
  • ¿Hay defectos visibles en manos, herramientas o tela?
  • ¿Podría confundirse con una fotografía de un taller o producto real? Preséntala como ilustración.
  • ¿Aparecieron servicios, instalaciones, marcas o testimonios que no existen?

Error frecuente: una aguja o una mano aparece deformada. Señala la zona concreta y pide corregirla; si persiste, descarta esa versión.

Coloca el cursor sobre la imagen y usa Descargar en tamaño completo si la opción aparece. Guarda también el prompt, la versión anterior y una nota sobre el uso previsto.

Hazlo tuyo

Adapta sujeto, entorno, composición, estilo y formato a un producto artesanal, una actividad cultural o un proyecto personal. Si necesitas mostrar un producto real, usa una foto fiel y autorizada; no presentes una imagen generada como prueba de características comerciales.
