Godot: encuentra el medallón

Crea un prototipo pequeño y comprueba el juego con tus propias acciones.

Volver al recorrido

Qué vas a conseguir

En una copia de práctica, construye un prototipo 2D: un personaje se mueve con las flechas, recoge un medallón, muestra un mensaje y puede reiniciarse con R. Después juégalo para comprobar cada acción.

Qué necesitas

Instala Godot, Node.js con npm (el conector requiere Node.js 18 o posterior) y un cliente MCP que pueda abrir el proyecto local y editar archivos. Esta ruta usa Claude Code, que requiere una cuenta con acceso. Consulta requisitos y comandos en el README del conector comunitario.

En el gestor de proyectos de Godot, crea un proyecto nuevo en una carpeta vacía y ábrelo. Verifica que esa carpeta contiene project.godot. No hay un proyecto base descargable probado en este curso: empezarás desde tu propio proyecto vacío. Mantén una copia de seguridad antes de pedir cambios.

Configura la conexión

  1. Abre una terminal en la carpeta de tu proyecto; comprueba que node, npm y claude funcionan. Inicia sesión en Claude Code siguiendo su guía oficial.
  2. Consulta claude mcp list. Si godot no figura, el README documenta claude mcp add godot -- npx @coding-solo/godot-mcp. Reinicia Claude Code y revisa el estado con /mcp.
  3. Si el conector no encuentra Godot, sigue la sección GODOT_PATH del README para indicar la ruta real del ejecutable. No copies una ruta de ejemplo.

La documentación del conector describe estas funciones y comandos; comprueba su resultado en tu equipo antes de seguir. El servidor Godot MCP puede inspeccionar y ejecutar proyectos y gestionar escenas; escribir scripts para el juego requiere además que el agente tenga acceso de escritura a los archivos de esta carpeta. Una respuesta con código en el chat no crea por sí sola un juego.

Prueba mínima del proyecto

Da al asistente la ruta absoluta de la carpeta que contiene project.godot. Pide consultar la versión de Godot y la información de ese proyecto mediante la conexión; compara la ruta que devuelve con la tuya. Después pide crear una escena de prueba Conexion.tscn con raíz Node2D y guardarla en esa copia. Comprueba en el panel de archivos de Godot que el archivo existe y se abre. Si solo te entrega instrucciones o código, la escritura conectada no está demostrada.

Esta es la ruta absoluta de mi proyecto de prueba: [pega la ruta de la carpeta que contiene project.godot]. Usa las herramientas de Godot para indicar la versión y los datos de ese proyecto; confirma la ruta antes de cambiar nada. Luego crea y guarda en esa copia una escena Conexion.tscn con raíz Node2D. No trabajes en otro proyecto. Si una herramienta no está disponible, detente y dilo.

Hazlo paso a paso

  1. Tras abrir Conexion.tscn, indica al agente que trabaje solo en la copia verificada. Pide que cree la escena principal y los archivos de script necesarios; comprueba que aparecen en el panel de archivos de Godot.
  2. Pide movimiento con las cuatro flechas. Ejecuta la escena y pulsa cada dirección.
  3. Pide un medallón que desaparezca una sola vez al tocarlo y muestre «Has encontrado el medallón».
  4. Ejecuta y juega: comprueba movimiento, recogida y mensaje.
  5. Pide reinicio con R; pulsa R y verifica que reaparezca el medallón y desaparezca el mensaje, manteniendo el movimiento.

Resultado esperado: una escena y scripts guardados dentro de tu proyecto, más un prototipo que puedas jugar. Obtener código o instrucciones en el chat sin archivos ni ejecución no cumple ese resultado.

Prompts copiables

1. Inspeccionar

Inspecciona esta copia del proyecto de práctica de Godot. Identifica la escena principal, ejecútala si tienes herramientas disponibles y comunica los mensajes de error. No cambies archivos todavía. Si no hay conexión activa, dilo.

2. Crear por etapas

En esta copia crea un prototipo 2D mínimo con formas locales: un personaje se mueve con las flechas y puede recoger un medallón. Al recogerlo, el medallón desaparece y aparece «Has encontrado el medallón». Trabaja primero el movimiento y después la recogida; ejecuta cada etapa y comunica los errores. Yo comprobaré el comportamiento jugando.

3. Mejorar

Añade una indicación para reiniciar con R. Al pulsarla, el medallón debe volver y el mensaje final desaparecer. Conserva el movimiento. Ejecuta el proyecto y comunica cualquier error; yo comprobaré las teclas en pantalla.

Comprueba, guarda y vuelve a abrir

En Godot, guarda la escena principal y confirma que los scripts están en el panel de archivos. Pulsa izquierda, derecha, arriba y abajo. Recoge el medallón y verifica que desaparece una sola vez y aparece el mensaje. Pulsa R y comprueba que el estado inicial vuelve. Cierra Godot, vuelve a abrir el proyecto desde su gestor y ejecuta de nuevo la escena principal. Que arranque sin errores no demuestra el comportamiento: repite las acciones jugando.

Si algo falla

  • Godot no aparece en el cliente: revisa claude mcp list, reinicia Claude Code y comprueba que Node.js y npm funcionan. Si el ejecutable no se detecta, configura GODOT_PATH según el README.
  • Ruta de proyecto inválida: selecciona la carpeta que contiene project.godot, no la carpeta superior ni otro juego.
  • El asistente devuelve código, pero no hay archivos: confirma que Claude Code tiene permiso de escritura en la copia; Godot MCP no sustituye por sí solo al editor de archivos. Detente si no puedes comprobar la escena de prueba.
  • No responde una flecha: anota cuál y pide revisar solo esa entrada.
  • El medallón se recoge varias veces: pide que se desactive al primer contacto y vuelve a probar.
  • R no restaura todo: comprueba por separado medallón, mensaje y movimiento.
