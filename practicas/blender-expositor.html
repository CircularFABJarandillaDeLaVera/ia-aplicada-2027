Blender: un pequeño expositor

Dirige una escena de formas simples, corrige un detalle y comprueba el archivo.

Volver al recorrido

Qué vas a conseguir

Prepara un pequeño expositor 3D con una base y tres productos ficticios. Cambia un detalle después de revisar la primera versión y guarda un archivo editable. La meta es comprobar una acción en Blender, no lograr un diseño profesional.

Qué necesitas

Instala Blender, uv, que incluye uvx, y un cliente MCP con acceso a tu ordenador. Esta ruta usa Claude Code, que requiere una cuenta con acceso; consulta sus condiciones antes de instalarlo. El proyecto comunitario MCP for Blender indica Blender 3.0+, Python 3.10+ y uv. Trabaja en una escena nueva o en una copia que puedas modificar; elige una carpeta local para guardarla.

Esta integración puede ejecutar código Python dentro de Blender. Guarda primero tu trabajo y mantén la conexión local. No actives descargas de modelos, generadores de pago ni servicios externos para esta práctica.

Configura la conexión

  1. Comprueba que Blender, uvx y claude abren desde tu equipo. Si falta alguno, sigue sus páginas de instalación enlazadas arriba.
  2. En una terminal, consulta claude mcp list. Si blender no existe, el README del proyecto documenta claude mcp add blender uvx mcp-for-blender.
  3. Instala el complemento con uvx mcp-for-blender install-addon. En Blender, abre Edit → Preferences → Add-ons y activa Interface: MCP for Blender.
  4. En la vista 3D pulsa N, abre la pestaña MCP for Blender e inicia la conexión con el botón que muestre tu versión. Reinicia Claude Code si acabas de añadir el servidor. Comprueba en /mcp que aparece activo.

Estos comandos y menús proceden del README mantenido del proyecto; comprueba cada paso en tu equipo antes de seguir. Ver «blender» en una lista no demuestra acceso a la escena.

Prueba mínima de la escena

En una escena de prueba, renombra un objeto visible en Blender con un nombre único que no escribirás en el chat. Si no hay objeto, añade un cubo y renómbralo. Pide al asistente que use get_scene_info y enumere los objetos reales. Comprueba que devuelve el nombre exacto y que corresponde a la escena abierta. Si no aparece, no sigas con la creación: la conexión no está demostrada.

Usa la herramienta de Blender conectada para consultar la escena abierta y enumera los nombres exactos de sus objetos. No te bases en una descripción anterior ni generes código para que yo lo ejecute. Si no puedes consultar la escena, dilo sin inventar su contenido.

Hazlo paso a paso

  1. Tras superar la prueba mínima, guarda una copia de la escena para esta práctica.
  2. Pide una base y tres piezas simples llamadas Base, Producto_A, Producto_B y Producto_C. Autoriza solo las acciones sobre esta escena.
  3. Observa en Blender tamaño, separación, colores y si las piezas se atraviesan.
  4. Pide una corrección concreta. Compara la vista frontal con la lateral.
  5. En Blender usa File → Save As para guardar expositor_v1.blend en tu carpeta local.

Resultado esperado: un archivo editable con cuatro objetos identificables y una mejora visible. Una explicación o un script escrito en el chat, sin cambios en Blender, es solo una propuesta.

Prompts copiables

1. Crear

Inspecciona la escena de práctica conectada y nombra los objetos que encuentres. En una copia, crea un expositor con una base y tres productos ficticios de formas simples llamados Base, Producto_A, Producto_B y Producto_C. Usa colores distintos y evita que se atraviesen. No uses modelos externos. Si no hay conexión activa, dilo sin afirmar que cambiaste la escena.

2. Mejorar

El producto central resulta demasiado alto. Reduce su altura un 20 %, mantenlo apoyado en la base y separa mejor las tres piezas. Muéstrame una vista frontal y otra lateral para revisarlas.

3. Guardar

Guarda la escena como expositor_v1.blend en la carpeta de práctica. Dime la ruta y los cambios realizados. Si no puedes guardar o mostrar la escena, explica qué falta sin afirmar que ya está hecho.

Comprueba, guarda y vuelve a abrir

Busca en Blender los cuatro nombres, verifica que las piezas no se atraviesan y compara el producto central antes y después de la corrección. Cierra el archivo y usa File → Open para volver a abrir expositor_v1.blend. Repite la inspección de objetos si quieres confirmar que la conexión sigue apuntando a esa escena. Si hay render, úsalo como ayuda visual; el archivo editable es la evidencia principal.

Si algo falla

  • uvx no se encuentra: termina su instalación, abre una terminal nueva y consulta la sección PATH del README del conector.
  • El asistente no ve el objeto de prueba: comprueba que el complemento está activo, que la pestaña MCP de Blender indica conexión y que solo hay un servidor iniciado. Reinicia el cliente si cambiaste la configuración. No continúes solo con una respuesta inventada.
  • Recibes código en el chat, pero la escena no cambia: pide explícitamente usar la herramienta conectada y mira Blender; ejecutar código por tu cuenta es otro recorrido.
  • Las piezas flotan o se cruzan: señala cuál y pide corregir solo su posición.
  • No se guarda: comprueba carpeta y permisos y usa File → Save As; no anuncies un archivo inexistente.
  • No hay render: revisa la escena en el visor de Blender; renderizar es opcional.
