# IA Aplicada 2027

Primera versión de prueba de Circular FAB. Curso abierto para profesionales, negocios, artesanos, asociaciones y personas con proyectos propios. Puedes entrar por la [teoría](teoria.html) o por cualquier práctica; no hay contenidos obligatorios ni acceso bloqueado por progreso.

Abre [index.html](index.html) para ir a la portada. Si lo tienes descargado, también puedes abrir ese archivo en un navegador. Para compartirlo como web, publica esta carpeta como sitio estático.
